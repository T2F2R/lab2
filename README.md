## Описание

- Java 8
- Аннотации `@Test`, `@Before`, `@After` (политика хранения `RUNTIME`, цель `METHOD`).
- `TestRunner.Run(Class<?>)` находит помеченные методы и запускает их.
- Для каждого теста создаётся **новый экземпляр** тестового класса.
- Порядок выполнения одного теста: `@Before` -> `@Test` -> `@After`.
- `@After` выполняются всегда, даже если упал `@Before` или сам тест.
- Исключение в одном методе не прерывает остальные.
- В конце выводится статистика: всего, успешно, упало.
- Логирование через стандартный `java.util.logging`, без внешних зависимостей.

Итог запуска: всего 4, успешно 2, упало 2.
