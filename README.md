## Цель работы

Реализовать простейший тестовый фреймворк на основе пользовательских аннотаций `@Test`, `@Before`, `@After`.

## Алгоритм работы, описание методов

### Алгоритм работы TestRunner.Run

1. Получить класс и найти в нём методы с аннотациями `@Before`, `@Test`, `@After` (методы каждой группы сортируются по имени для предсказуемого порядка).
2. Для каждого метода `@Test`:
   1. создать новый экземпляр тестового класса через конструктор без параметров;
   2. выполнить все методы `@Before`;
   3. если все `@Before` прошли, выполнить тестовый метод;
   4. выполнить все методы `@After`, причём всегда, даже если `@Before` или тест упали;
   5. тест считается успешным, только если ни один из вызванных методов не бросил исключение.
3. Исключение в одном методе логируется и не прерывает выполнение остальных.
4. После всех тестов вывести статистику: всего, успешно, упало.

### Аннотации

| Аннотация | Назначение |
|-----------|------------|
| `@Test` | Метод является тестом. |
| `@Before` | Метод выполняется перед каждым тестом (таких методов может быть несколько). |
| `@After` | Метод выполняется после каждого теста (таких методов может быть несколько). |

Все три имеют политику хранения RUNTIME и применяются только к методам.

### Методы класса TestRunner

| Метод | Описание |
|-------|----------|
| `public static void Run(Class<?> testedClass)` | Точка входа: находит методы, запускает каждый тест, выводит статистику. |
| `private static boolean runSingleTest(...)` | Выполняет одну связку Before → Test → After на новом экземпляре; возвращает `true`, если всё прошло без исключений. |
| `private static List<Method> findMethods(Class<?>, Class<? extends Annotation>)` | Возвращает методы класса с заданной аннотацией, отсортированные по имени. |
| `private static boolean invokeAll(Object, List<Method>)` | Вызывает список методов; исключение одного не мешает остальным; возвращает `true`, если ошибок не было. |
| `private static void invoke(Object, Method)` | Вызывает метод через рефлексию и извлекает реальное исключение из `InvocationTargetException`. |
| `private static Object createInstance(Class<?>)` | Создаёт экземпляр класса через конструктор без параметров. |
| `private static void printStatistics(int total, int passed)` | Логирует итоговую статистику. |

### Тестируемый класс MyClass

| Метод | Описание |
|-------|----------|
| `int getSum(int a, int b)` | Возвращает сумму `a + b`. |
| `int getMultiplication(int a, int b)` | Возвращает произведение `a * b`. |
| `int getDivision(int a, int b)` | Возвращает `a / b`; при `b == 0` бросает `IllegalArgumentException`. |

### Тестовый класс MyClassTest

| Метод | Описание |
|-------|----------|
| `before1()`, `before2()` | `@Before`: создание объекта `MyClass` и логирование. |
| `after1()`, `after2()` | `@After`: логирование завершения. |
| `getSumTest_twoPositiveNumber()` | `@Test`: проверка суммы положительных чисел; намеренно бросает `RuntimeException("Broken test")`. |
| `getSumTest_twoNegativeNumber()` | `@Test`: проверка суммы отрицательных чисел (успешно). |
| `getMultiplicationTest_twoPositiveNumber()` | `@Test`: проверка произведения (успешно). |
| `getDivisionTest_byZero()` | `@Test`: деление на ноль, падает с `IllegalArgumentException`. |

Итог запуска: всего 4, успешно 2, упало 2.
